# Credential-shaped bindings that the guard still finds in the scanned entry
# points. Each line is `path count classification`.
#
# The counts are a TWO-DIRECTIONAL ratchet. A path not listed here must have
# none. A listed path may not exceed its count. A listed path that has FEWER
# than its count fails too, and the fix is to lower the number in the same
# change — an allowance that outlives the thing it allowed is a hole that
# reopens silently.
#
# Nothing here records a value. A line names a file, a number and a reason.
#
# Two classifications, kept apart on purpose:
#
#   reviewed      Looked at, and correct as it stands. The premise that makes
#                 it correct is asserted by a named test in
#                 test_credential_literals.py — an exemption whose premise is
#                 not checked is a hole, not an exemption. If the premise
#                 stops holding, that test fails before the ratchet does.
#
#   grandfathered Real debt, allowed only until someone removes it. No entry
#                 carries this today. Do not add one without an owner and a
#                 removal plan; "it was already there" is not a premise.
#
# reviewed
