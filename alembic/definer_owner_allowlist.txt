# SECURITY DEFINER functions the migrator (app_admin) is allowed to leave owned
# by itself. One schema-qualified signature per line, argument types spelled as
# PostgreSQL prints them (oidvectortypes). Anything else that a migration
# creates as SECURITY DEFINER is refused by alembic/env.py and the whole run
# rolls back: a definer function runs with its owner's privileges, and the
# migrator owns BYPASSRLS.
#
# Adding a line here is a security decision. It needs the same review as
# changing the role contract, never a baseline exception.

public.settle_outbox_event(uuid, text, text, timestamp with time zone, integer, text)
